# Promotion Gate

The complete simultaneous replay, not only the bounded integration test, has
satisfied exact workload integrity for 112 VC0 contexts and four VC1 groups.
The full trace also compares both ready decisions, output validity, and the
selected VC at every cycle for all sixteen endpoints against independent
arbiter cycle models. Functional policy promotion is therefore satisfied.

Physical promotion requires hierarchy-matched timing, area, and power. The
composed measurement may replace separate-network costs only when one shared
mesh and all producer datapaths are represented in the measured hierarchy.

Architecture promotion additionally requires feeding those measurements into
the Llama7B model and re-running the throughput, energy, area, and precision
comparison against the current frontier.

The 15,769-cycle eager-producer service envelope is a standalone capacity
bound only. Throughput promotion requires a replay driven by actual VC0 SRAM
residency events and VC1 reducer valid/ready group releases.
