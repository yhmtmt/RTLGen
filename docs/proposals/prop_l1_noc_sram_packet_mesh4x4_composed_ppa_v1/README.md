# Composed SRAM Endpoint Mesh PPA

The v1 evaluation is superseded and must not be dispatched. It depends on the
obsolete aggregate-mesh v1 result and an endpoint r4 result whose selected
setup path has not been proven, while its fixed 3.2 mm square floorplan is not
matched to the composed macro.

An r2 synthesis prefilter and physical sweep will be derived from aggregate
r4. The replacement must retain all sixteen endpoints and routers, quantify
compact harness overhead, and use a floorplan justified by measured hierarchy
area and pin constraints.
